
# Mezgebe Sbhat

Mezgebe Sbhat is a Flutter-based mobile application created to support the learning and preservation of Ethiopian Orthodox Tewahedo Church hymns. The application combines audio recordings with corresponding written texts, allowing users to listen and read simultaneously for a more effective learning experience.

## Overview

Many existing hymn applications provide audio recordings but do not include the corresponding written texts. Mezgebe Sbhat addresses this gap by integrating PDF versions of hymns and prayers alongside audio playback, making it easier for deacons, students, and believers to follow, study, and memorize liturgical content.

The application is designed to be simple, accessible, and suitable for users of all ages.

## Features

* Audio playback for Ethiopian Orthodox hymns
* PDF text integration for corresponding hymns and prayers
* Offline access to downloaded content
* Clean and user-friendly interface
* Organized hymn categories and navigation
* Support for Ge'ez and Amharic texts
* Free to use with no advertisements

## Target Users

* Deacons
* Sunday school students
* Choir members
* Ethiopian Orthodox faithful
* Anyone interested in learning Orthodox hymns and prayers

## Purpose

The primary goal of Mezgebe Sbhat is to make Ethiopian Orthodox hymn education more accessible by bringing audio and written resources together in a single application. By preserving traditional liturgical content in a digital format, the application helps users learn, practice, and deepen their understanding of Orthodox worship.

## Technology Stack

* Flutter
* Dart
* PDF Viewer
* Audio Playback Services
